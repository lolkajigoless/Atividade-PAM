# Rastreador de Entregas

Aplicativo mobile desenvolvido com **React Native e Expo**.

## Requisitos

- Node.js
- npm
- Expo CLI (utilizado via `npx`)
- Android Studio e Android SDK (para gerar o APK localmente)
- Java JDK compatível com a versão do React Native

## Instalação

Clone o repositório:

```bash
git clone https://github.com/lolkajigoless/Atividade-PAM.git
cd Atividade-PAM
```

Instale as dependências:

```bash
npm install
```

Corrija possíveis incompatibilidades entre as dependências e a versão do Expo:

```bash
npx expo install --fix
```

## Executar o projeto

Inicie o servidor de desenvolvimento:

```bash
npx expo start
```

Para executar diretamente no Android:

```bash
npx expo start --android
```

## Reinstalar as dependências

Caso seja necessário instalar todos os pacotes novamente:

```bash
npm install
```

o arquivo estará no repositório
